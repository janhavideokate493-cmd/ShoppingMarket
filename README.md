# 🛒 Shopping Market

A simple shopping cart web application built using HTML, CSS, and JavaScript.

## ✨ Features

- Select fruits from the market
- Enter quantity
- Automatic price calculation
- Running final bill
- User-friendly interface
- Responsive design

## 🍎 Available Fruits

| Fruit | Price |
|---------|---------|
| Mangoes | ₹50 |
| Apples | ₹50 |
| Banana | ₹60 |
| Cherry | ₹30 |
| Strawberry | ₹50 |

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Download the project
2. Open `index.html`
3. Enter fruit name and quantity
4. Click **Add To Cart**
